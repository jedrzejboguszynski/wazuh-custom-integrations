# Wazuh Integration: DefectDojo

A custom integration to automate vulnerability management and streamline DevSecOps workflows by bridging **DefectDojo** findings with **Wazuh SIEM**.

## Overview
This integration enables automated ingestion of application and dependency vulnerabilities into Wazuh. By fetching active findings from DefectDojo on a scheduled basis, SOC teams can detect new security risks, track unresolved issues, and generate centralized alerts for triage, compliance (such as the European Cyber Resilience Act), and SOAR workflows.
